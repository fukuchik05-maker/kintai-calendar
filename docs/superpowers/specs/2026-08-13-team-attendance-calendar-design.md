# カレンダー形式 勤怠管理ツール 設計書

- 日付: 2026-08-13
- ステータス: 承認済み

## 背景・目的

家族または少人数チーム(3人想定、後から人数変更可能)の勤怠(出退勤・休暇)を、
カレンダー形式で一覧管理するツールを作る。サーバーやインストール作業なしで、
HTMLファイルをダブルクリックするだけで使えることを重視する。

## 全体方針

- **単一HTMLファイル**にHTML/CSS/JSをすべて埋め込み。ビルド不要、外部ライブラリ不要。
  file:// で直接開いても動作すること。
- **データ保存はブラウザのLocalStorage**。プロフィール切り替えではなく、
  1つの共有データセットの中に複数メンバー分の記録を持つ「チームシフト表」形式。
- 対象人数は初期状態で未設定。設定画面でメンバーを自由に登録・編集・削除できる
  (3人程度を想定するが人数固定ではない)。

## データモデル

```js
{
  "members": [
    { "id": "m1", "name": "田中", "grantedLeaveDays": 20 },
    { "id": "m2", "name": "鈴木", "grantedLeaveDays": 20 },
    { "id": "m3", "name": "佐藤", "grantedLeaveDays": 20 }
  ],
  "records": {
    "2026-08-13": {
      "m1": {
        "status": "出勤",       // 出勤 / 休日 / 有給 / 半休 / 欠勤 / その他
        "clockIn": "08:30",
        "clockOut": "18:10",
        "breakMin": 60,
        "hourlyLeaveHours": 0,  // 出勤日にオプションで入力する時間有給
        "note": ""
      }
    }
  }
}
```

- LocalStorageキーは1つ(例: `kintai-data-v1`)にJSON全体を保存。
- 祝日データは別途、コード内に静的テーブル(2024〜2027年、日本の国民の祝日)として埋め込む。
  年が進んだら手動でテーブルを追記する。

## 画面構成

1. **ヘッダー**
   - 年月切り替え(◀ 2026年8月 ▶、「今月」ボタン)
   - 「メンバー設定」ボタン
   - 「CSV出力」ボタン
   - 「データのバックアップ／復元」ボタン(JSONファイルの書き出し・読み込み)

2. **カレンダー本体(月グリッド)**
   - 1マス=1日。マスの中にメンバー全員分の行を縦に並べる
     (氏名の頭文字 + ステータス色ドット + 出退勤の短縮表示、例: `田 08:30-18:10`)
   - 土曜/日曜/祝日は背景色を変えて区別
   - その日にメンバーの残業が発生している場合、そのメンバー行の残業部分
     (時刻や時間表示)をオレンジ/赤系の色で強調表示
   - メンバー行をクリック → そのメンバー・その日の編集モーダルを開く

3. **編集モーダル**
   - 対象メンバー名・日付を表示
   - ステータス選択: 出勤 / 休日 / 有給 / 半休 / 欠勤 / その他
   - ステータスを「出勤」にすると、出勤・退勤欄に既定値 08:30 / 17:30 を自動プリセット
     (実際の時刻が違えば上書き編集)
   - 休憩時間(分)
   - 時間有給(時間) ※出勤日のみ入力可能な任意項目
   - 備考欄
   - 保存 / この日の記録を削除

4. **月間集計パネル(カレンダー下)**
   - メンバーごとに以下を表形式で表示:
     出勤日数 / 実労働時間合計 / 残業時間合計(強調色) / 有給消化日数 / 有給残日数 / 欠勤日数
   - 表示中の月を対象に自動集計

5. **月報ビュー**
   - メンバーを選んで、その月の「出勤日数・実労働時間・残業時間・有給消化・有給残」を
     見やすくまとめた印刷向けレイアウトで表示(集計パネルの内容を1人分に絞った拡大版)

6. **メンバー設定モーダル**
   - メンバーの追加・氏名編集・削除
   - 各メンバーの「有給付与日数」を設定

## 計算ロジック(すべて純粋関数として分離し、単体テスト可能にする)

- **実労働時間** = 退勤時刻 − 出勤時刻 − 休憩(分)。出退勤が両方入力されている時のみ計算。
- **残業時間** = (08:30より前に出勤した分) + (17:30より後に退勤した分)。
  15分未満切り捨て。ステータスが「出勤」の日のみ対象。
- **有給残日数** = 付与日数 − Σ(有給=1日、半休=0.5日、時間有給=時間/8日)。
  全期間の記録を対象に累計で消化分を差し引く(特定の月だけでなく、記録されている全日付が対象)。
  月報・月間集計パネルに表示する「有給残」は、その月末時点までの記録を集計した値とする。
  一方「有給消化日数」は表示中の月だけの消化数を表す。
- 半休・時間有給は実労働時間の計算対象外(有給残の消化のみ扱う)。

## エクスポート/インポート

- **CSV出力**: 表示中の月を対象に、列は
  `日付,氏名,ステータス,出勤,退勤,休憩(分),時間有給(時間),実労働時間,残業時間,備考`。
  Excelで文字化けしないようUTF-8 BOM付きで出力。
- **JSONバックアップ/復元**: LocalStorage全体をJSONファイルへ書き出し/読み込みするボタンを設置。
  誤操作によるデータ全消去に備えた保険。

## テスト方針

ビルドなしの単一HTMLのため、フレームワークでの自動テストは組まない。代わりに:

- 実労働時間・残業時間・有給残計算・CSV整形などの純粋関数を分離し、
  Node.jsから直接requireして簡易アサーションで単体テストするスクリプトを用意する。
- ブラウザでの手動確認チェックリストを用意する:
  - 日をまたぐ勤務時刻の入力
  - 出退勤未入力時の表示・集計への影響
  - メンバーの追加・編集・削除
  - 祝日・土日の色分け
  - 残業発生時の色分け表示
  - 有給/半休/時間有給を組み合わせた際の残日数計算
  - CSV出力の文字化け確認
  - ページ再読み込み後のデータ保持

## スコープ外(今回はやらないこと)

- 複数端末間でのデータ同期(サーバー・DB連携)
- ログイン認証・アクセス制御
- 祝日データの自動更新(API連携)
- モバイル最適化の作り込み(最低限のレスポンシブ対応のみ)
